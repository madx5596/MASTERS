# 🔄 ИНСТРУКЦИЯ ПО ОТКАТУ

## Если что-то сломалось после изменений:

### 1. Проверьте сборку
```bash
npm run build
```

Если есть ошибки TypeScript - исправьте их или откатитесь к SNAPSHOT.

### 2. Проверьте запуск
```bash
npm run dev
```

Откройте http://localhost:5173 и проверьте:
- Login работает
- Все страницы загружаются
- Чат работает
- Навигация работает

### 3. Если нужно откатиться

**Вариант A: Git (если используете)**
```bash
git status
git diff
git checkout .
```

**Вариант B: Ручной откат**
Сравните проблемные файлы с SNAPSHOT.md и восстановите их содержимое.

### 4. Ключевые файлы для проверки

Если что-то не работает, проверьте эти файлы:

- `src/App.tsx` - роутинг
- `src/store/index.ts` - store
- `src/api/client.ts` - API клиент
- `src/hooks/useCurrentUser.ts` - хуки
- `src/pages/shared/ChatPage.tsx` - чат
- `src/components/layouts/index.tsx` - навигация
