## 3. КАКИЕ API ДОБАВЛЕНЫ

### Frontend Store Methods (локальные, для demo mode):

```typescript
// Services
addService(service)
updateService(id, updates)
deleteService(id)

// Promotions
addPromotion(promotion)
updatePromotion(id, updates)

// Advertisements
addAdvertisement(ad)
updateAdvertisement(id, updates)

// Providers
updateProvider(id, updates)
```

**Примечание:** Эти методы работают с Zustand store в demo mode.  
Для API mode необходимо реализовать backend endpoints:
- `POST /api/services`
- `PATCH /api/services/:id`
- `DELETE /api/services/:id`
- `POST /api/promotions`
- `PATCH /api/promotions/:id`
- `POST /api/advertisements`
- `PATCH /api/advertisements/:id`
