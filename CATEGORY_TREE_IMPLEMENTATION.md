- `removeProviderFromCategory()` - отвязать мастера
- `getProviderCategories()` - получить категории мастера

**Защита:**

- Проверка зависимостей перед удалением
- Автоматическая генерация slug
- Уникальность slug

**Созданы routes:** `server/src/routes/categories.ts`

**Endpoints:**
```
GET    /api/categories              - все категории
GET    /api/categories/tree         - дерево категорий
GET    /api/categories/roots        - корневые категории
GET    /api/categories/search?q=    - поиск
GET    /api/categories/slug/:slug   - по slug
GET    /api/categories/:id          - по ID
GET    /api/categories/:id/children - дети
GET    /api/categories/:id/path     - путь
POST   /api/categories              - создать
PATCH  /api/categories/:id          - обновить
PATCH  /api/categories/:id/move     - переместить
PATCH  /api/categories/:id/archive  - архивировать
DELETE /api/categories/:id          - удалить
POST   /api/categories/:id/providers/:providerId - привязать мастера
DELETE /api/categories/:id/providers/:providerId - отвязать мастера
GET    /api/categories/providers/:providerId/categories - категории мастера
```

**Права доступа:**
- `GET` - все авторизованные пользователи
- `POST/PATCH/DELETE` - только SUPER_ADMIN и CONTENT_ADMIN

   - Нажать "✎" рядом с категорией

6. **Удаление:**
   - Нажать "🗑" рядом с категорией

2. **Поиск по названию:**
   - Клиент вводит "маникюр"
   - Система находит все категории с "маникюр" в названии

## 🔒 БЕЗОПАСНОСТЬ

### Защита от ошибок:

1. **Циклические ссылки:**
   - Триггер `check_category_cycle()` проверяет при INSERT/UPDATE
   - Нельзя создать категорию, которая является своим же предком

2. **Удаление с зависимостями:**
   - Нельзя удалить категорию, если:
     - Есть услуги, привязанные к ней
     - Есть мастера, работающие в ней
     - Есть дочерние категории
   - Вместо удаления предлагается архивирование

3. **Уникальность slug:**
   - Триггер `generate_category_slug()` генерирует уникальный slug
   - Если slug уже существует, добавляется суффикс

4. **Глубина иерархии:**
   - Максимальная глубина: 100 уровней
   - Защита от бесконечных циклов
